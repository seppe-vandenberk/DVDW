THE TWO-MINUTE EXPLANATION

How does a computer
learn to play?

Try moves. See what happens. Use that experience next time. This AI repeats that process thousands of times.

1. It learns from practice.

We give it the rules of Connect Four, but not a list of winning strategies. It plays against other AI versions, a rule-based player, and a random player. Finished human games also give it experience.

A win earns +1, a draw 0, and a loss −1. Quick wins are better; delaying a loss is better than losing immediately. Learning from the results of actions is called reinforcement learning.

2. Its model learns board patterns.

A model is a set of adjustable numbers. Ours is a small neural network: connected calculations that learn to recognise useful patterns. Practice adjusts those numbers so its predictions better match its examples.

It does not chat like ChatGPT. It reads the board and makes these two predictions.

3. It looks ahead before choosing.

The AI also tries possible moves in its game engine: “If I play here, what could my opponent do?” It follows promising paths and checks possible replies.

During practice, it learns from both the moves this search explored and how the real game ended. It can still make mistakes: it cannot check every possible future.
