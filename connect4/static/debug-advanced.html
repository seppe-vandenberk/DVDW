Architecture and what changed

The default DQN learner was replaced by a policy/value network with PUCT tree search, local batched games, and outcome-based learning. Physical games retain the validated, retry-safe API. Learning runs in a background thread in the API process, using separate weights from the published model.

The old DQN source and old checkpoints were preserved. The original README moved to LEGACY_DQN.md. New models use az-*.pt and az-*.learner.pt. The game rules, 7×5 board, rule opponent, and camera contract were retained.

Exhibition games are inference-only. Background practice uses 60% recent published opponents, 25% rules, and 15% random. Confirmed external games contribute a bounded share of replay. The learning reward is win +1 / draw 0 / loss −1, discounted by 0.997 per ply.

This console exposes measurements; it does not guarantee five-hour mastery. Export a snapshot to compare runs or attach it to a bug report.
