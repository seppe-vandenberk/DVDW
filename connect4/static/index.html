Measuring the starting strength of each model…

Score = (wins + half the draws) / games. Search learning checks 20 games against the rule opponent, equally as each color, with fixed opening seeds. Candidate checks run in the background about every five minutes; a separate match against the published model decides whether to publish new weights. The chart includes candidates that were not published. Human play uses the published model while training continues. These samples measure progress, not proof of unbeatable play. Legacy DQN checks use 50 games every 250 updates.
